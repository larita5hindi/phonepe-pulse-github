# PhonePe Transaction Insights Dashboard

## Project Overview
This project is a Streamlit dashboard built using Python and MySQL.
It visualizes PhonePe transaction data across states and years.

## Technologies Used
- Python
- Streamlit
- MySQL
- Pandas
- Matplotlib

## Features
- State-wise filtering
- Year-wise filtering
- Total transaction amount
- Total transaction count
- Transaction type analysis
- Yearly trend visualization

## How to Run
streamlit run app.py
